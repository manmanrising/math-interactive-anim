# 题型建模对照表

按「一眼认出题型 → 直接套建模」组织。每类给出：识别特征、参数、`stateAt` 要算什么、画什么、答案特征、跳转点。

---

## 1. 一维数轴动点

**识别**：数轴上 A、B、C 表示某数；点 P/Q 以某速度运动；求「相距 d 的时刻」「追上/相遇」「中点」。

**参数**：时间 `t`，范围 `0 → 总时长`，步长 `0.05`。

**stateAt 要点**：
- 位置函数 `p = 起点 + 速度 × t`（向左为减）
- 有停止条件时，用 `Math.min(t, 停止时刻)` 截断
- 往返运动写成**分段函数**，每段写成 `a + v×t` 或 `a − v×t` 的形式
- 分段边界要写清 `t < t1` / `t <= t1`，端点归属错了答案会多一个或少一个

**画什么**：
- 数轴（横线 + 箭头 + 整数刻度）
- 定点用小三角 + 标签 `A(−12)` 这种合并写法；刻度数字要跳过这些位置避免重复
- 动点画在轴的上方/下方各一侧（P 上、Q 下），各带一条竖虚线投到轴，避免两点重合时看不清
- 两点距离用双箭头标注 + 数值

**答案特征**：通常有多个解（`t = 2, 8, 10, 14.5, 15.5`），需要逐段解方程。

**跳转点**：每个解一个按钮，标注「跳到 t = 8」。

**边界陷阱**：某点可能还没出发（停在起点），此时距离公式仍然成立，但是否计入答案要看题面表述。答题时列出并注明。

**范例**：`assets/example-numberline.html`

## 2. 单参数平面动点

**识别**：点在定直线、定线段、抛物线、圆上运动；求长度、面积、角度。

**参数**：用**动点的横坐标或角度**当参数最省事。点在抛物线上就用 `x = t`，`y = f(t)`；点在圆上就用 `θ = t`，`x = r·cos θ, y = r·sin θ`。

**stateAt**：返回动点坐标 + 所有待求量（长度、面积、角度）。

**画什么**：坐标系（开 `uniform:true`）、曲线（采样成 path，步长 0.02）、定点、动点、从动点引出的线段/多边形、高线用虚线。

**答案特征**：最值通常出现在顶点、中点、垂足处。

**跳转点**：起点、极值点、终点。

**范例**：`assets/example-parabola.html`

## 3. 图形性质验证

**识别**：三角形内角和、平行线的内错角/同旁内角、中位线、垂直平分线；题目本身不是求值而是「验证某关系恒成立」。

**参数**：能改变图形形状的那个自由度。例如平行线题就用截线与平行线的夹角；三角形题就用某个顶角。

**画什么**：把待验证的角用扇形弧线标出并实时显示度数，或在边上标注长度。关键是让用户在拖动时看到「无论怎么变，这两个数始终相等/相加等于 180」。

**答案特征**：答案为恒等关系，不是具体数值。

**跳转点**：可以让跳到「题设条件成立的那个位置」（例如题目给定 ∠AEF = 65°，就加一个跳转到 65° 的按钮）。

## 4. 折叠与对称

**识别**：矩形/菱形/正方形沿某条线折叠，某点落到某处；求折痕长度、最小周长。

**参数**：折痕的落点位置（例如折痕与某边的交点的横坐标）。

**stateAt 要点**：
- 折叠的本质是**轴对称**：折叠后的点 = 原点关于折痕的镜像
- 两点关于直线 `ax+by+c=0` 的镜像公式：
  ```
  d = (a·x0 + b·y0 + c) / (a² + b²)
  x' = x0 − 2a·d
  y' = y0 − 2b·d
  ```
- 折痕是两点连线的**垂直平分线**
- 折叠后图形用 `transform="rotate(...)"` 或直接算镜像点坐标重画（算坐标更可控）

**画什么**：原图形（实线）、折后图形（半透明或虚线）、折痕（醒目色）、对称点。

**答案特征**：最值常出现在「三点共线」或「垂线段最短」的时刻。

**验证技巧**：把「折后点」和「目标位置」画出来，让用户拖到它们重合，重合瞬间亮起徽标。

## 5. 动点最值（将军饮马 / 垂线段最短 / 两点间线段最短）

**识别**：求 `PA + PB` 最小值、`PA − PB` 最大值、某折线路径最短。

**参数**：动点沿某条定直线/定曲线的位置参数。

**stateAt 要点**：
- 直接算 `|PA| + |PB|`，不要试图解析求最值
- 同时算出**理论最小值**和**取到最小值的动点位置**，用于画「最优位置」标记

**画什么**：
- 动点、两条线段、实时长度和
- 用绿色小圆点标出理论最优位置（用户拖到附近时和它重合）
- 当 `|值 − 理论最值| < 0.06` 时，弹出「✓ 已达最小值」徽标

**答案特征**：将军饮马型答案通常是「对称点连线与定直线的交点」，最小值 = 两点间距离。

**跳转点**：最优位置。

## 6. 轨迹问题（瓜豆原理 / 阿氏圆）

**识别**：问「点 P 运动的轨迹是什么」「轨迹长度是多少」。

**参数**：主动点的位置参数。

**stateAt 要点**：算出从动点坐标。若轨迹是圆，同时算出圆心与半径（用三点定圆或解析推导）。

**画什么**：
- 从动点
- **轨迹**：把从动点在一整个参数周期内的位置采样成折线，用浅色实线画出来（不要用 `trace` 动画，直接算完一次性画）
- 圆心、半径标注（若为圆）

**关键体验**：用户拖动主动点时，从动点必须**恰好落在预先画好的轨迹线上**。这是最好的正确性证明——如果偏离，说明公式错了。

**答案特征**：轨迹为圆/直线/线段；长度 = 弧长或线段长。

## 7. 函数图像与动点面积

**识别**：抛物线与坐标轴交点、动点在图象上、求三角形/四边形面积最值、面积等于某值时求点坐标。

**参数**：动点横坐标 `t`。

**stateAt**：
```
y = f(t)
面积 = 0.5 × 底边长 × |y|      （底边在 x 轴上时）
```

**画什么**：坐标系、函数曲线、定点、动点、多边形填充（`fill-opacity: 0.10`）、高线（虚线）、面积数值贴在三角形重心处。

**答案特征**：面积最值出现在顶点，或由配方 `a(t−h)² + k` 直接读出。

**跳转点**：顶点（面积最大）、两端交点、面积等于某值的两个解。

---

## 8. 旋转与位似

**识别**：绕定点旋转某角度、位似放大缩小、手拉手模型。

**参数**：旋转角 `θ`（单位度）或位似比 `k`。

**stateAt**：对每个顶点套旋转矩阵
```
x' = cx + (x−cx)cosθ − (y−cy)sinθ
y' = cy + (x−cx)sinθ + (y−cy)cosθ
```

**画什么**：原图（实线）+ 变换后图形（半透明填充）+ 旋转中心 + 对应点连线。

**关键体验**：拖动 θ 时，对应点之间的连线应当始终交于旋转中心——这本身就是旋转的定义，用户看到就懂了。

## 通用设计要点

**读数卡片别超过 4 个**。超过就分不清主次，只放「题目要求解的那个量 + 它的两个中间量」。

**颜色语义固定**：
- 蓝 `#0a84ff` —— 第一个动点 / 主要对象
- 红 `#ff3b30` —— 第二个动点 / 目标对象
- 绿 `#34c759` —— 距离、达标状态、答案
- 橙 `#ff9500` —— 高线、辅助线
- 紫 `#5e5ce6` —— 函数曲线、变换后图形

**参数范围要贴着题目**。题目说 P 到 C 停止，滑块上限就设成那一刻，不要给到 100。

**步长与精度匹配**。答案含 14.5 这种半整数时，步长必须 ≤ 0.05，否则拖不到。读数保留 2 位小数。
